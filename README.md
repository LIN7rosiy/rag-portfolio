# RAG PDF QA Application

一个基于 Streamlit 和 LangChain 构建的本地文档智能问答工具（RAG）。用户可以上传 PDF 文档，AI 将根据文档内容进行精准问答。

## 📌 项目来源与致谢 (Acknowledgments)
本项目的基础架构复现并重构自著名开源项目 **Awesome LLM Apps** 中的 `chat_with_pdf` 模板。
- **原项目链接**: [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)
